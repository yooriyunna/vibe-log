## 오늘 만든 것
리다이렉트 목록을 엑셀에서 복사해 붙여넣으면 **문제 있는 행을 골라서 보여주는 도구**. 첫 업무용 도구다.
→ [바로 써보기](https://yooriyunna.github.io/vibe-log/demos/redirect-checker/) ("예시 넣기" 버튼을 누르면 어떤 식으로 잡아내는지 볼 수 있다)

잡아내는 것:
- **충돌** — 같은 구 URL인데 신 URL이 서로 다름
- **순환** — A→B→A처럼 돌고 돌아 페이지가 안 열림
- **자기 자신** — 구 URL과 신 URL이 같음
- **체인** — A→B→C로 여러 번 건너뜀 → A→C로 바로 보내라고 최종 목적지를 제안
- **국가 불일치** — `/sg/` 페이지가 `/uk/`로 가는 경우
- **임시(30x)** — 301이 아닌 302·307
- **중복** — 완전히 같은 행

정리본(중복 제거 + 체인을 최종 목적지로 펼친 버전)은 버튼 하나로 복사해서 엑셀에 바로 붙여넣거나 CSV로 받을 수 있다.

## 프롬프트·과정
> 리다이렉트 URL 정리기 만들자

- 크롤러 내보내기 형식(Address / Redirect URL / Status Code)도, 그냥 두 열짜리 목록도 받도록 했다. 첫 줄이 머리글이면 열 이름으로 위치를 찾는다.
- URL 비교 전에 정규화: 도메인 무시, 끝 슬래시 무시, 대소문자 무시를 옵션으로 켜고 끌 수 있다. `/category/tv/`와 `/category/tv`를 같은 것으로 볼지는 사이트마다 다르니까.
- 회사 URL을 넣어도 괜찮도록 **서버 없이 브라우저 안에서만** 처리한다.
- 예시 데이터로 일부러 모든 유형의 문제를 하나씩 넣어서, 12행 중 9행이 정확히 잡히는지 확인했다.

## 막힌 점
- 체인을 따라가다 순환에 빠지면 무한 반복이 된다. 지나온 URL을 기억해 두고, 다시 만나면 "순환"으로 표시하고 멈추게 했다.
- 같은 구 URL이 여러 번 나오면 어느 쪽을 따라갈지 애매하다. 일단 첫 번째 행을 기준으로 따라가고, 그 행들은 "충돌"로 따로 표시해서 사람이 정하도록 했다.
