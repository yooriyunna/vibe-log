## 오늘 만든 것
매일 바이브코딩한 내용을 남길 기록 사이트. 마크다운 파일 하나 push하면 글이 올라가고, 홈에 연속 기록일수와 최근 12주 잔디가 보인다.

## 프롬프트·과정
> Astro 기반 기록 사이트 뼈대(목록 페이지, 글 템플릿, GitHub Pages 배포 설정)를 만들어줘

- 글 템플릿을 5칸으로 고정해서 1분 안에 기록할 수 있게 했다.
- `npm run new` 한 번이면 오늘 날짜 파일이 생긴다.

## 막힌 점
- **배포 후 글 링크가 404** — 글 주소가 `/vibe-log/logs/...`가 아니라 `/logs/...`로 만들어졌다.
  원인은 `astro.config.mjs`의 `base`가 `'/'`로 되어 있던 것. 저장소 이름이 `<아이디>.github.io`가 아니면 사이트가 `/<저장소이름>/` 아래에 올라가니까, `base: '/vibe-log'`로 맞춰야 한다.
- GitHub 첫 사용이라 Clone → 파일 복사 → Commit → Push 흐름을 익히는 데 시간이 조금 걸렸다. 숨김 폴더 `.github`를 빠뜨리지 않는 것도 포인트.
