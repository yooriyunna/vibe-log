리다이렉트 URL 정리기

엑셀에서 리다이렉트 목록을 복사해 붙여넣으면 중복·충돌·체인·순환·국가 불일치를 찾아 줘요. 입력한 데이터는 브라우저 밖으로 나가지 않아요.

열 순서: 1열 = 구 URL(From), 2열 = 신 URL(To), 3열 = 상태코드(선택). 머리글에 Address / Redirect URL / Status Code가 있으면 그 이름으로 열을 찾아요.

#구 URL (From)신 URL (To)최종 목적지 (제안)단계코드문제
  • 중복 From·To가 똑같은 행이 또 있음 — 정리본에서 1개만 남겨요
  • 충돌 같은 From인데 To가 서로 다름 — 하나로 정해야 해요
  • 체인 To가 다시 다른 곳으로 리다이렉트됨 — 최종 목적지로 바로 보내는 게 좋아요
  • 순환 돌고 돌아 다시 자기에게 돌아옴 — 페이지가 안 열려요
  • 자기 자신 From과 To가 같음
  • 국가 불일치 From과 최종 목적지의 국가 코드(/sg/, /uk/ 등)가 다름
  • 임시(30x) 301이 아닌 302·307 등 — 영구 이전이면 301이 맞아요
